实现
niucloud/addon/baijia_tools 是本项目自定义原生应用；未购买商业插件。
首页使用 niucloud 原生 DIY_INDEX 富文本、图文导航与底部导航，由站点后台管理。
优惠计算、省钱指南和说明页面位于原始 uni-app 工程的 addon/baijia_tools 分包。
计算在本地执行，历史记录只保存到设备。首页配置从自建服务器读取。
当前不提供领券、下单、返佣或品牌供应商服务。

维护
在后台“站点管理”访问百迦好省，进入“装修管理 → 启动页 → 装修”。
文字、图文导航、横幅与底部导航可通过原生后台修改。
前端源码以 niucloud/addon/baijia_tools/uni-app 为准；编译前同步到
uni-app/src/addon/baijia_tools，避免两份副本漂移。
初始安装脚本 scripts/setup-baijia-site.php 只用于首次初始化，不覆盖已有站点。
使用 PHP 进程用户 www 执行它，不要使用 root 生成运行缓存。
服务器备份位于 /root/baijia-backup-20261109/，权限仅限服务器管理员。

构建（仓库根目录进入 uni-app）
export VITE_SITE_ID=100000
export VITE_APP_BASE_URL=https://mini.baijia.life/api/
export VITE_IMG_DOMAIN=https://mini.baijia.life
export NIU_SKIP_WEB_COPY=1
npm run build:h5
npm run build:mp-weixin

NIU_SKIP_WEB_COPY=1 保留 niucloud H5 多站点路由处理，但不覆盖仓库已跟踪的 public/wap。
原生编译产物为 uni-app/dist/build/mp-weixin；不要选择之前的 tools 独立工程。
在微信开发者工具导入该目录；AppID 已写入 project.config.json。
当前已配置 mini.baijia.life 的 HTTPS；根域名 baijia.life 保留原站。
微信公众平台仍须将 https://mini.baijia.life 加入 request/downloadFile 合法域名。
不能将 /api/ 路径填写到合法域名设置中。
开发工具内临时跳过域名校验的预览不等于真机或发布验收。
