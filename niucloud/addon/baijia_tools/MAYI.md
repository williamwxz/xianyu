# 蚂蚁星球接入

小程序「首页 → 更多 → 蚂蚁星球」提供话费电费和美团券包。「我的订单 → 蚂蚁星球订单」按登录会员查询充值、点餐及影票订单。肯德基和热门电影入口使用的确省页面，服务器按当前城市读取供应商目录。订单列表只展示使用同一跟单 UID 的记录。

在服务端 niucloud 的 .env 中设置以下项目，保存后通过正常的配置刷新流程生效。

```ini
[HAOJINGKE]
SITE_ID = 100000
APIKEY = <供应商分配的推广标识>
SECRET = <供应商签名密钥>
UID_KEY = <本地生成的稳定随机密钥>
```

用 openssl rand -hex 32 生成 UID_KEY，保存在服务器配置和备份中。更改此值会改变会员对应的跟单 UID。半屏页面接收 APIKEY 和跟单 UID。SECRET 和 UID_KEY 只供服务器使用。

微信公众平台「设置 → 第三方设置 → 半屏小程序管理」添加 wx5f482af87ff127ca，确认对应商户已获充值及券包权限。上传新开发版后，从首页打开充值服务，返回小程序核对查单归属、状态和金额。

[半屏服务及接入要求](https://www.haojingke.com/default/pluginembedded) · [订单查询及签名](https://www.haojingke.com/index.php/default/plugin)

## 商户点餐与影讯

商户后台「开发管理 → 点餐充值API → 开发文档」包含点餐和影票交易协议。的确省的 `native/kfc` 和 `native/movies` 只调用目录，分别读取点餐和电影城市映射。北京两套目录的城市编号分别为 2 和 3，应以各接口实际返回值为准。供应商请求使用 HTTPS，密钥只在站点服务端配置。

- 肯德基门店、菜单按用户操作查询。预览展示菜单参考价；供应商的下单校验还涉及规格、数量和最终金额。
- 影片、影院和场次均来自影票目录。当前开发版支持浏览。
- 供应商创建交易订单会消耗备付金，需要商户确认点餐与影票权限、费用、支付和退款流程。商户页面还限制为比价或维护商品库而进行的采集，增加渠道时须核对对应授权。

[商户接入页](https://www.haojingke.com/center/index.html#/personal/develop/paytrilateral) · [肯德基门店文档](https://s.apifox.cn/018c1fc9-de2b-4246-972c-65e853244073/api-118013391) · [影票热映文档](https://s.apifox.cn/018c1fc9-de2b-4246-972c-65e853244073/api-259100061)

## 自选座影票验收

从热门电影选择影片、影院、场次和座位。确认手机号后生成 15 分钟有效的站内报价，最迟到该场次停售为止。服务端重新读取区域票价和座位，并调用蚂蚁星球的订单校验。会员可在「我的订单 → 电影 → 自选座影票」查看详情。

首次实单验收时，先核对商户备付金、影院、场次、座位、售价和站内订单号。商户同意后，服务端可将 `HAOJINGKE.MOVIE_APPROVED_ORDER` 配置为这一个完整订单号。默认值为空。微信支付使用该会员的服务端 openid。保持本单配置至出票请求提交，切勿将该项写入小程序。

已有站点升级时应用 install.sql 中新增的 baijia_movie_order 表，安装 baijia_movie_order_sync 每分钟任务。任务核对框架支付流水后提交出票。提交超时后以原第三方订单号查单。商户可凭订单号在供应商后台核实长时间未确认的请求。供应商确认关闭后通过原微信流水退款。取票码仅返回给下单会员。
